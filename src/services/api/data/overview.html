OSTS API Overview

OSTS API

A JSON API exposing Slayer Diaries Monster Entries, Slayer Masters, and Clan Rank data for the Old School Tool Set bot.

Version: v1
Format: JSON only
Base URL: /API/v1/
Live
API Details
Base URL https://osts.website/API/v1/
Auth None required
Response UTF-8 JSON
Success 200 — resource body
Not Found 404 — structured JSON error
CDN Netlify Edge
Quickstart
⚡
Try it now
Run these from your terminal or bot
# Clan rank icons
curl https://osts.website/API/v1/Clan/Rank/icons.json

# Slayer diary entry (monster slug)
curl https://osts.website/API/v1/Slayer_Diaries/Monster/Entries/Aberrant_spectre.json

# Slayer master portraits
curl https://osts.website/API/v1/Slayer_Master/Head/icons.json
Core Endpoints
GET
/API/v1/Clan/Rank/icons.json
Clan rank icons and basic metadata.
GET
/API/v1/Slayer_Diaries/Monster/Entries/<name>.json
Per‑monster Slayer diary entries, keyed by slug name (e.g. Aberrant_spectre).
GET
/API/v1/Slayer_Master/Head/icons.json
Slayer master portrait icons.
Responses & Usage
📡
Bot & overlay friendly
No auth, versioned, edge-cached
Auth No authentication required.
Versioning All endpoints live under /API/v1/ for stability.
Caching Served from Netlify's CDN edge — fast globally.
Errors Unknown resources return a structured 404 JSON body.
